# Password Vault (Basic)

An educational offline password reminder built with Expo, React Native, TypeScript,
React Navigation, and AsyncStorage.

So this is the question that we are asked to work on 

GROUP 4. Password Vault (Basic)
🔐 Stores passwords locally (educational)
What the app does
● Saves login details for personal reference
Specifications
● Add app name, username, password
● Mask passwords on screen
● Store locally with AsyncStorage
● Optional: simple PIN lock (no encryption)
⚠️ Educational only — no advanced security
Real-World Use
Password reminder (offline)


Features of the project 

1. Add app name, username and password
2. Hide (mask) the passwords on screen
3. Save the data on the phone with Async Storage
4. Optional: a simple PIN lock (no encryption)
